# Tokenizer 2 - Coat of Arms

A coat of arms generator for [Tokenizer 2](https://github.com/MrPrimate/tokenizer-2), inspired by *Pendragon*.

See the [Coat of Arms documentation](https://docs.ddb.mrprimate.co.uk/docs/tokenizer-2/coat-of-arms) for how to use it.

## Installation

Requires the Tokenizer 2 module.

Install in Foundry Modules Manager directly or with this manifest URL:

```
https://github.com/MrPrimate/tokenizer-2-coat-of-arms/releases/download/latest/module.json
```
